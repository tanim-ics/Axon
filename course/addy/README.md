# Course text: "Agent Engineer" by Addy Osmani

These files are the lesson text shown by Axon's full-read mode.

- **Source:** https://github.com/addyosmani/agent-engineer (also published at https://addyosmani.com/agents/)
- **Author:** Addy Osmani
- **Licence:** Apache License 2.0. The full text is in `LICENSE.txt` in this folder.
- **Downloaded:** 2026-11-15, the 19 lesson `README.md` files from the `main` branch.

## What was changed

- Each lesson's `README.md` was saved as `md/NN.md`, where `NN` is the lesson number.
- The interactive HTML widgets and their inline scripts were removed. A one-line note marks each
  place: "The original lesson has an interactive demo here. Open the original to try it."
- Runs of blank lines were collapsed. Nothing else in the text was edited.
- `NN.js` holds the same text as `md/NN.md`, wrapped so the app can load it. These files are
  generated by `tools/build-course.js`; do not edit them by hand.

The key-lesson cards, puzzles and questions in the app's Addy journey are separate. They were
written for Axon in its own words and are not part of the course text.

## Updating a lesson

1. Download the lesson's `README.md` into `md/NN.md`.
2. Run `node tools/build-course.js` straight away. It removes embedded HTML from `md/NN.md` and
   rebuilds `NN.js`.
3. Run `npm test`.
